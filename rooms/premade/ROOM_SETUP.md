# Premade Room Setup

The generator now builds the floor graph first and then picks a premade room scene based on:

- stage world folder
- room type folder
- exact doorway pattern folder

The lookup path is:

```text
res://rooms/premade/stage_<world>/<room_type>/<door_pattern>/
```

Examples:

```text
res://rooms/premade/stage_1/combat/north_east/
res://rooms/premade/stage_1/reward/east_west/
res://rooms/premade/stage_2/boss/north_south_west/
```

## Important Rule

The game no longer rotates room scenes after loading them.

If the graph needs a room with `north + east` doors, it will only look inside:

```text
res://rooms/premade/stage_<world>/<room_type>/east_north/
```

That means you should build each doorway combination as its own correct layout.

## Where To Build Rooms

Create your room scene files inside:

- `rooms/premade/stage_1/start/...`
- `rooms/premade/stage_1/combat/...`
- `rooms/premade/stage_1/boss/...`
- `rooms/premade/stage_1/reward/...`
- `rooms/premade/stage_1/rest/...`
- `rooms/premade/stage_1/debuff/...`

Repeat the same structure later for `stage_2`, `stage_3`, and so on.

## Door Pattern Folder Names

Folder names are generated by sorting the connected sides alphabetically and joining them with `_`.

Use these exact names:

- `east`
- `north`
- `south`
- `west`
- `east_north`
- `east_south`
- `north_south`
- `north_west`
- `south_west`
- `east_west`
- `east_north_south`
- `east_north_west`
- `east_south_west`
- `north_south_west`
- `east_north_south_west`

## Best Workflow

1. Duplicate `res://rooms/graph_room.tscn`
2. Replace the placeholder walls/floor with your real tileset layout
3. Keep the required node names and markers
4. Save the new room scene into the correct `stage/type/door_pattern` folder

Example:

```text
Duplicate: res://rooms/graph_room.tscn
Save as:   res://rooms/premade/stage_1/combat/east_north/combat_east_north_a.tscn
```

## Required Nodes To Keep

Every premade room scene must keep these nodes so the generator and gameplay still work:

- `Floor`
- `RoomLabel`
- `Markers/PlayerSpawn`
- `Markers/NorthDoor`
- `Markers/SouthDoor`
- `Markers/WestDoor`
- `Markers/EastDoor`
- `Markers/EnemySpawns`
- `RewardInteractable`
- `StageExitInteractable`
- `ActivationZone`

The room root should still use:

```text
res://scripts/stage_room.gd
```

## What To Place In Each Pattern Folder

Each folder should contain layouts whose door openings match the folder name exactly.

Examples:

- `east_north` means the room has only east and north exits
- `north_south` means the room has only top and bottom exits
- `east_north_west` means the room has east, north, and west exits
- `east_north_south_west` means the room is open on all four sides

Do not rely on rotation to convert one version into another.

## Start And Boss Rooms

Start rooms and boss rooms are both leaf rooms now.

That means they should only be built in the one-door folders:

- `east`
- `north`
- `south`
- `west`

You do not need multi-door variants for `start` or `boss`.

## Vertical Mirror Constraint

Because your top-down art should not be rotated freely, this exact-pattern setup is the safer approach.

You can still vertically mirror while building art if that helps your tileset workflow, but the code itself will not mirror or rotate rooms for you.

## Recommended First Build Set

Start with stage 1 combat and the most common doorway patterns:

- `rooms/premade/stage_1/combat/east/`
- `rooms/premade/stage_1/combat/north/`
- `rooms/premade/stage_1/combat/south/`
- `rooms/premade/stage_1/combat/west/`
- `rooms/premade/stage_1/combat/east_north/`
- `rooms/premade/stage_1/combat/east_south/`
- `rooms/premade/stage_1/combat/north_south/`
- `rooms/premade/stage_1/combat/north_west/`
- `rooms/premade/stage_1/combat/south_west/`
- `rooms/premade/stage_1/combat/east_west/`

Then add:

- `stage_1/start/...`
- `stage_1/boss/...`
- `stage_1/reward/...`
- `stage_1/rest/...`

If a folder has no `.tscn` files yet, the game falls back to `res://rooms/graph_room.tscn`.
